# 每日运势签 · 抽签占卜

一个纯前端的小游戏：点击签筒抽一支签，占卜当天的运势。

> ⚠️ 仅供娱乐，无任何科学依据，请理性看待。

## 功能

- 点击签筒摇签，动画出签后展示结果
- 签级五档：上上签 / 上签 / 中签 / 下签 / 下下签
- 每签包含：签文、解签、幸运数字、幸运颜色、幸运方位、运势星级，以及「宜 / 忌」建议
- 支持「再抽一签」，并显示当天日期

## 使用

直接用浏览器打开 `index.html` 即可，无需任何依赖或构建。

或通过 GitHub Pages 访问：https://quella-hub.github.io/daily-fortune/

## 技术栈

- 原生 HTML + CSS + JavaScript，单文件，无外部依赖
